# Titelbilder — Ablage & Reihenfolge

Hier liegen die Titelbilder für das Modul „Muhammad in der Bibel" und seine Siegel.
Die Komponenten erwarten **exakt diese Dateinamen** (Endung `.jpg` **oder** `.png` —
beide werden automatisch erkannt; wenn kein Bild vorhanden ist, zeigt das Karussell
eine gestaltete Pergament-Platzhalter-Karte).

## Modul-Titelbild (Hero oben auf der Modul-Seite)

| Datei                       | Verwendung                                  |
|-----------------------------|---------------------------------------------|
| `module/muhammad.jpg`       | Großes Titelbild „Muhammad in der Bibel" ﷺ  |

## Siegel-Titelbilder (Karussell) — in DIESER Reihenfolge hochladen

Die Reihenfolge entspricht 1:1 der Aufstellung der Siegel auf der Seite:

> **Tipp:** Wenn du die Bilder einfach als `1.jpg … 9.jpg` (in obiger Reihenfolge)
> ablieferst, benenne ich sie auf die obigen Namen um. Der Titel (Fundament / Siegel I…VII /
> Verteidigung) wird von der Karussell-Komponente **automatisch unter das Bild** gesetzt —
> du musst ihn nicht ins Bild einbauen (kannst es aber, falls gewünscht).

**Empfohlenes Seitenverhältnis der Karten:** ~3:4 (Hochformat), z. B. 900×1200 px.
**Hero-Bild:** Querformat ~21:9 bis 16:9, mind. 1600 px Breite.
