# Bild-Ablage (Referenz-Assets)

Lege deine fertigen Bilder **hier in diesen Ordner** und committe sie auf den
Branch `claude/vibrant-allen-syff24`. Ich nutze sie dann direkt im Daniel-Kapitel
(die Statue mit klickbaren Zonen darüber, den Stein als heranrollendes Element).

## Erwartete Dateien (Namen bitte genau so)

| Datei | Inhalt | Format |
|---|---|---|
| `statue.png` | Die Nebukadnezar-Statue, **freigestellt** (transparenter Hintergrund) | PNG mit Transparenz |
| `stein.png` | Der Stein / die leuchtende Kugel, am besten freigestellt | PNG (oder JPG) |
| `karte.png` | (optional) deine Karte | PNG/JPG |

Andere Formate (`.jpg`, `.webp`) sind auch ok — sag mir einfach Bescheid,
welche Datei was ist.

## So lädst du sie hoch (ohne lokales Git)

1. Öffne das Repo auf **github.com/aymanoul/Ayman**.
2. Oben den Branch auf **`claude/vibrant-allen-syff24`** umstellen.
3. In den Ordner `public/refs/` wechseln → **„Add file" → „Upload files"**.
4. Bilder reinziehen → **„Commit changes"** (Commit direkt auf diesen Branch).

Danach sage ich kurz Bescheid bzw. du schreibst „hochgeladen" — ich hole sie
und baue sie ein.
