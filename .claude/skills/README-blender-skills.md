(+ references/reference-image-match.md, visual-match-checklist.md).

Wichtig:
- Die festen Regeln aus gebet-video/CLAUDE.md gehen immer vor (z. B. keine Augen/Augenbrauen: Hinweise wie „blink“ oder
  „eyes“-Material gelten hier nicht).

  bpy (.venv-blender); die Tipps zu Licht, Kamera, Rendern, Animation und Materialien gelten trotzdem.
